# Uniform AIF startup prefix

`tools/aif_uniform_prefix.py` generates the composition for the first 21 time
slabs in all eight parameter bins. Successful Lean replay gives the original
compiled AIF circuit a nonempty set of realizations and proves that every such
realization has output between zero and `16/5` on the closed interval
`[0,21/200]`, for every fixed real `eta` in `[8,12]`.

Seven bin modules dispatch the checked drift and output certificates. Bin zero
reuses the earlier 21-cell result; the other bins reuse their checked first
cell and supply the next 20 cells each. The final module derives moving-tube
membership from the actual circuit's zero initialization and derivative law,
then uses the output enclosures. The endpoint and parameter boundaries are
closed, so adjacent cells and bins cover their shared endpoints.

The final theorem has no assumed tube membership or missing certificate family.
This is a bounded startup result: the full time-30 startup tube still needs its
remaining cells. The separate forward-safety composition remains conditional on
complete drift and output families. Global existence, forward uniqueness and
nonnegativity come from the previously checked circuit-solution theorem.

Generation alone is not proof. Replay must check all generated modules and
all imported cell certificates with the Lean kernel, audit their axiom reports,
and preserve the compiler and import fingerprints. The batch records exact
compiler commands, completion receipts, source and artifact hashes, and the
independent stage audits. `--check` compares generated bytes without creating
or repairing files.
